Claude Code web sessions

Web sessions run in cloud containers, so they can't be file-watched. Point their HTTP hooks at a relay (an ntfy.sh topic works: https://ntfy.sh/<long-random-topic>) and AI Keeper subscribes to it.

Paste the copied JSON into the repo's .claude/settings.json (merge with existing hooks), commit it, and allow the relay domain in the web environment's network settings. Save settings here first so the snippet uses your relay URL.
